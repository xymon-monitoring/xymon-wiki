# AI-assisted contribution

Contributions produced with AI assistance are welcome in every repository here,
under the same rules as any other: reviewed the same way, held to the same
standard, judged on the change rather than on how it was written.

What governs the work is the repository you are working in, not this page. An
agent runs in a checkout and reads what it finds there, so `xymon` carries
[AGENTS.md](https://github.com/xymon-monitoring/xymon/blob/main/AGENTS.md) for
coding agents and
[CONTRIBUTING.md](https://github.com/xymon-monitoring/xymon/blob/main/CONTRIBUTING.md)
for every contributor. Those are authoritative for that tree and this page does
not restate them.

Where a repository has no `AGENTS.md` of its own — the wiki, the plugins, the
Windows PowerShell client — two rules still hold:

- **Never present as real anything you did not observe.** A test result, a
  command's output, a version, a platform you did not run on. "I could not test
  this" is an accepted answer; an invented one is not.
- **Report the finding, not the tool.** Use whatever assistance you like, then
  say what changed and why in your own words. No repository here credits a model
  or an assistant in a commit, a pull request or a file.
